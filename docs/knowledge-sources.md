# Sources for the additional coding prompts

Researched on 25 October 2026. These 11 additions complement the original 18 seeds. They are original task templates informed by primary documentation, not copied vendor prompts. All new files use `kind: prompt` and the existing seed parser's front matter. Angle-bracket placeholders identify information the user or repository must supply.

Generic templates preserve existing stack/provider choices. Stack-specific templates apply only when that technology is present or its adoption has been selected. A cited vendor is not a recommendation to adopt its products. Published guidance supports the engineering principles; it does not establish that these templates improve model quality by a measured amount.

The Next.js template was checked against the installed `next` 16.4.3 documentation: `frontend/node_modules/next/dist/docs/01-app/01-getting-started/05-server-and-client-components.md` and `01-app/02-guides/server-and-client-boundary.md`. It directs future users to their own installed version. OpenTelemetry's GenAI conventions have moved to their dedicated repository and remain evolving; the template deliberately avoids prescribing a potentially stale metric name. The OpenAPI link is an explicit version reference, not an instruction to upgrade.

The additions contain brief paraphrases with source links, no copied examples or long excerpts. All 29 seeds passed the existing parser and have unique titles. On 25 October 2026, all 11 additions were loaded through the app's normal knowledge API, bringing the stored total to 29. Each stored body matched its seed and had a generated summary plus 3–5 retrieval tags. [Ingestion evidence](evidence/knowledge-additions.json) records the item IDs and counts. This verifies ingestion and availability, not a measured improvement in suggestion quality.
